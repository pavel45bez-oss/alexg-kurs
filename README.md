# Курс FX Alex G — интерактивный конспект

Неофициальный учебный конспект бесплатного 10-часового курса Алекса G
([видео на YouTube](https://www.youtube.com/watch?v=grw58BIzotU)) и его открытых роликов
про поддержку и сопротивление.

Внутри:

- **Полный курс** — 43 урока в 14 модулях: структура рынка, зоны интереса, пробой и ретест,
  свечные подтверждения, голова и плечи, EMA 50, риск-менеджмент, разбор челленджа.
  В каждом уроке пересказ, правила с цитатами (перевод и оригинал), ошибки, примеры, термины и тест.
- **Графики с номерами** — у каждой линии и зоны номер, под графиком легенда; наведение подсвечивает элемент.
  21 схема фигур и реальные дневные/недельные графики 28 валютных пар.
- **Курс на 3 дня** и тренажёр: построение зон на 28 парах, ретесты, калькулятор риска.
- Итоговый экзамен, прогресс сохраняется в браузере.

Пересказ и переводы — мои, в кавычках — слова Алекса. Это учебный материал, не инвестиционная рекомендация.
Котировки — OANDA через TradingView на 03.11.2026.

## Запуск локально

```bash
cd web
npm install
npm run dev
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте этот проект в ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После пуша workflow `Deploy to GitHub Pages` соберёт сайт; ссылка появится во вкладке **Actions**
   и в **Settings → Pages** (вида `https://<ваш-логин>.github.io/<репозиторий>/`).

## Структура

- `web/` — сайт (Vite + React).
- `data/full/lessons/` — уроки в JSON.
- `data/fx.json` — котировки и зоны для графиков.
- `tools/gen.py` — генератор `fx.json` (нужен сырой дамп `data/raw/`, он не входит в репозиторий).
